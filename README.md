# Консольный ассистент ProxyAPI

Программа общается с моделями через ProxyAPI и предлагает два режима: обычный OpenAI Chat Completions (`GPT-4o mini`) и думающий `Claude 4.5 Sonnet`. Для Claude показываются доступные reasoning-блоки и расход токенов. История автоматически сохраняется в `data/history.json` и загружается при следующем запуске.

## Как запустить

1. Создайте ключ в личном кабинете ProxyAPI и вставьте его в `.env`:

   ```env
   PROXYAPI_API_KEY=ваш_ключ
   ```

2. В PowerShell активируйте готовое окружение и запустите программу:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   python main.py
   ```

Если окружение нужно пересоздать: `py -m venv .venv`, затем `pip install -r requirements.txt`.

При запуске выберите режим `1` или `2` (по умолчанию — Claude). Команды: `exit`, `quit` или `выход` завершают чат; `/history` показывает историю; `/clear` удаляет её.

## Что реализовано

- два API-режима через официальный SDK OpenAI и Anthropic;
- сохранение контекста между запросами и запусками;
- таймауты, повторные попытки и понятные сообщения об ошибках;
- настройки моделей, лимитов и адресов API через `.env`;
- офлайн-тесты истории и API-форматов: установите `requirements-dev.txt` и выполните `python -m pytest`.
